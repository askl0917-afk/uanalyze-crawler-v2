# UAnalyze Crawler v2 Multi CSV

- 第一區塊：維持原本產業情報欄位長時間爬蟲。
- 第二區塊：可獨立執行，只登入一次、進虎八速覽、輸入一次股票代號，然後依序下載多張圖表 CSV。
- 第二區塊目前包含：
  1. 累計月營收追蹤(實際營收vs法人vs我的預估)-新版
  2. 季EPS表現追蹤(實際VS法人共識)
  3. 季營收表現追蹤(實際VS法人共識)
  4. 季毛利率表現追蹤(實際VS法人共識)
  5. 營收趨勢與利潤率比較圖（會先點「季度」再下載 CSV）
  6. 存貨銷售比(月)(每季更新一次)
  7. 合約負債VS佔營收比重VS季營收
  8. 存貨細項(原始科目)
- 股票代號欄位只輸入數字，例如 3030。
- 第二區塊不需要先跑第一區塊；也不會改動第一區塊原本的爬蟲流程。
